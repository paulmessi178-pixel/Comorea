Informatique 10 Modules Complets

Module 1 / 10
📚 Informatique / Introduction à l'informatique
01

Introduction à l'informatique

Débutant
⏱ 6 étapes • 2h30
Comprendre ce qu'est un ordinateur, son fonctionnement interne et le vocabulaire de base de l'informatique. Ce module pose les bases essentielles pour toute la suite du parcours.
1
Définition de l'informatique : science du traitement automatique de l'information. Comprendre la notion de données (data) et de programme.
2
Les composants physiques (hardware) : processeur (CPU), mémoire vive (RAM), disque dur (HDD/SSD), carte mère, carte graphique (GPU), alimentation.
3
Les logiciels (software) : système d'exploitation (Windows, Linux, macOS), applications, drivers. Différence hardware vs software.
4
Le cycle de traitement : Entrée → Traitement → Sortie → Stockage. Exemples concrets avec clavier, CPU, écran.
5
Les unités de mesure : bit, octet (byte), Ko, Mo, Go, To. Calculs de conversion et exemples pratiques (photos, vidéos, etc.).
6
Les types d'ordinateurs : PC de bureau, laptop, serveur, tablette, microcontrôleur. Cas d'utilisation de chacun.
🎯
Mini-Projet Dresser une fiche descriptive complète d'un ordinateur réel : identifier et nommer tous les composants visibles, noter les caractéristiques (RAM, stockage, processeur) et calculer la capacité totale en Go.
02

Systèmes d'exploitation

Débutant
⏱ 7 étapes • 3h
Maîtriser l'interface et les fonctions fondamentales d'un système d'exploitation. Apprendre à gérer fichiers, dossiers, paramètres et raccourcis pour travailler efficacement au quotidien.
1
Rôle d'un OS : gestion du matériel, des processus, des fichiers et des utilisateurs. Présentation de Windows 10/11, Ubuntu Linux, macOS.
2
Bureau, barre des tâches, gestionnaire de fichiers. Navigation dans l'arborescence : C:\Users\ (Windows) ou /home/ (Linux).
3
Créer, renommer, déplacer, copier, supprimer des fichiers et dossiers. Comprendre les extensions de fichiers : .txt, .pdf, .jpg, .exe, etc.
4
Panneau de configuration / Paramètres : résolution d'écran, comptes utilisateurs, mises à jour, gestion des applications installées.
5
Raccourcis clavier indispensables : Ctrl+C/V/X/Z, Alt+Tab, Win+E, Ctrl+Alt+Del. Augmente la productivité de 40%.
6
Gestionnaire des tâches : surveiller CPU, RAM, disque. Terminer un processus bloqué. Identifier les programmes qui ralentissent le PC.
7
Introduction au terminal / invite de commandes : commandes cd, ls/dir, mkdir, del/rm. Puissance de la ligne de commande.
🎯
Mini-Projet Organiser un espace de travail complet : créer une arborescence de dossiers (Travail > Projets > [Année] > [Mois]), y placer des fichiers types, puis réaliser les mêmes opérations en ligne de commande.
03

Internet & Réseaux

Débutant
⏱ 7 étapes • 3h
Comprendre comment fonctionne Internet, les protocoles de communication, les adresses IP, et naviguer de manière efficace et sécurisée sur le Web.
1
Qu'est-ce qu'un réseau ? LAN (réseau local), WAN (réseau étendu), Internet. Notion de client/serveur. Comment les données voyagent en paquets.
2
Adresse IP : IPv4 (192.168.1.1) et IPv6. Adresse MAC. Rôle du routeur, du modem, du switch. Connexion Wi-Fi vs Ethernet.
3
Protocoles essentiels : HTTP/HTTPS, FTP, DNS, DHCP. Comment un navigateur charge une page web (DNS → IP → TCP → HTML).
4
Les navigateurs web : Chrome, Firefox, Edge. Onglets, favoris, historique, mode privé. Moteurs de recherche et opérateurs avancés ("", site:, filetype:).
5
Sécurité en ligne : reconnaître HTTPS (cadenas), phishing, mots de passe forts, double authentification (2FA). Gestionnaires de mots de passe.
6
Email professionnel : rédiger, CC/BCC, pièces jointes, signatures. Différence Gmail, Outlook, Thunderbird. Organiser sa boîte mail avec des filtres et dossiers.
7
Cloud computing : Google Drive, OneDrive, Dropbox. Synchronisation, partage de fichiers, accès multi-appareils. Avantages du cloud vs stockage local.
🎯
Mini-Projet Configurer un environnement numérique personnel : créer un compte email professionnel, organiser sa boîte mail, stocker 5 documents importants sur le cloud et les partager avec un lien, puis tester sa connexion réseau avec ping et ipconfig.
04

HTML & CSS — Bases du Web

Intermédiaire
⏱ 7 étapes • 4h
Créer vos premières pages web avec HTML pour la structure et CSS pour le style. Comprendre comment les sites internet sont construits de zéro, sans framework.
1
Structure d'un document HTML : <!DOCTYPE html>, <html>, <head>, <body>. Balises sémantiques : <header>, <main>, <footer>, <section>.
2
Texte et liens : <h1>–<h6>, <p>, <strong>, <em>, <a href="">. Images : <img src="" alt="">. Listes : <ul>, <ol>, <li>.
3
Formulaires HTML : <form>, <input>, <textarea>, <select>, <button>. Attributs type, name, placeholder, required.
4
CSS — sélecteurs : tag, .classe, #id, combinateurs. Propriétés fondamentales : color, background, font-size, margin, padding, border.
5
Le modèle de boîte (box model) : content → padding → border → margin. box-sizing: border-box. Positionnement : static, relative, absolute, fixed.
6
Mise en page moderne : Flexbox (display:flex) et CSS Grid (display:grid). Responsive design avec @media.
7
Variables CSS (:root), animations CSS (@keyframes), transitions et pseudo-classes (:hover, :focus).
🎯
Mini-Projet Créer une page de portfolio personnel complète : une section hero, une grille de compétences, un formulaire de contact fonctionnel, et un design responsive.
05

JavaScript — Programmation Web

Intermédiaire
⏱ 7 étapes • 4h30
Rendre vos pages web interactives et dynamiques avec JavaScript. Du DOM à la manipulation d'événements, ce module est la clé pour créer des sites vivants.
1
Bases du JS : variables (let, const), types, opérateurs. console.log() pour déboguer.
2
Structures de contrôle : if/else, switch, boucles. Fonctions : déclaration, paramètres, return, fonctions fléchées.
3
Tableaux et objets : .push(), .map(), .filter(), .reduce(). Déstructuration, spread operator.
4
Le DOM : document.getElementById(), querySelector(). Modifier contenu, style, classes.
5
Événements : addEventListener('click', fn), 'input', 'submit'. Objet event, preventDefault().
6
JavaScript asynchrone : setTimeout, Promises, async/await. Fetch API pour charger des données JSON.
7
LocalStorage : localStorage.setItem(), getItem(). Sauvegarder et récupérer des données côté navigateur.
🎯
Mini-Projet Créer une application "Liste de tâches" complète : ajouter/supprimer/cocher des tâches, filtrer par statut, sauvegarder dans LocalStorage. Interface stylée.

Projet Final — Application Web Complète

Expert
⏱ 7 étapes • 20h+
Mettre en pratique TOUS les concepts du parcours en créant une application web complète de A à Z : front-end, back-end, base de données, sécurité, déploiement. C'est votre chef-d'œuvre.
1
Conception : définir les fonctionnalités, créer les wireframes (Figma), modéliser la base de données, choisir la stack technique.
2
Base de données : créer les tables SQL, relations, index. Rédiger les requêtes CRUD. Préparer les données de test.
3
Back-end : créer une API REST simple avec Python (Flask) ou Node.js (Express). Endpoints : GET, POST, PUT, DELETE.
4
Front-end : interface HTML/CSS/JS responsive. Consommer l'API avec fetch(). Formulaires avec validation côté client.
5
Sécurité : hacher les mots de passe (bcrypt), authentification par sessions ou JWT, protection contre les injections SQL.
6
Tests & Débogage : tester les endpoints avec Postman, corriger les bugs. Rédiger des tests unitaires basiques.
7
Déploiement : héberger sur un VPS, configurer un nom de domaine, activer HTTPS avec Let's Encrypt. Votre application est en ligne 🚀
🏆
Projet Final Créer et déployer une plateforme de blog avec inscription/connexion, publication d'articles, système de commentaires, tableau de bord admin, et interface responsive. Présenter le projet avec démo live et rapport technique.

Robotique 6 Modules Pratiques

0% Complété
01

Introduction à la Robotique

Débutant
⏱ 5 étapes • 2h
Découvrez les fondamentaux de la robotique, les composants essentiels et les applications dans le monde réel. Une excellente introduction pour débuter.
1
Qu'est-ce qu'un robot ? Définition, types et applications. Robots industriels, domestiques, médicaux et éducatifs.
2
Composants d'un robot : moteurs, capteurs, contrôleurs, alimentations. Rôle de chaque composant dans le fonctionnement.
3
Systèmes de mobilité : roues, jambes, bras articulés. Cinématique et dynamique basiques.
4
Plates-formes robotiques populaires : Arduino, Raspberry Pi, LEGO Mindstorms. Leurs avantages et cas d'usage.
5
Éthique et sécurité en robotique. Normes ISO et bonnes pratiques pour un développement responsable.
🎯
Mini-Projet Analyser un robot réel (ou vidéo) : identifier ses composants, ses capteurs, sa mobilité et son application.
02

Arduino et Microcontrôleurs

Intermédiaire
⏱ 6 étapes • 3h
Programmez des microcontrôleurs Arduino pour contrôler des capteurs et des actuateurs. Apprenez l'électronique basique et la programmation embarquée.
1
Présentation d'Arduino : carte, broches, LED, boutons. Installation de l'IDE Arduino et premiers programmes.
2
Langage de programmation Arduino (dérivé de C++). Variables, boucles, fonctions. Structure setup() et loop().
3
Entrées/Sorties numériques et analogiques. digitalWrite(), digitalRead(), analogWrite(), analogRead().
4
Capteurs courants : température, distance, lumière, mouvements. Branchement et lecture des données.
5
Contrôle de moteurs : moteurs DC, servo, moteurs pas à pas. Pilotes moteurs et PWM.
6
Projets pratiques : feu tricolore, système d'alerte, contrôle de température. Intégration de plusieurs capteurs.
🎯
Mini-Projet Créer un système de feu tricolore avec Arduino : LED rouge/orange/vert qui alternent, avec durées variables.
03

Robotique Mobile : Robots Roulants

Intermédiaire
⏱ 6 étapes • 4h
Construisez et programmez des robots mobiles capables de se déplacer, détecter les obstacles et naviguer de manière autonome.
1
Chassis et motorisation : réducteurs, engrenages, rapport de réduction. Sélectionner moteurs et batteries appropriés.
2
Transmission et différentiel : deux moteurs pour tourner. Contrôle indépendant des roues gauche/droite.
3
Capteurs de navigation : ultrasons pour détecter obstacles, encodeurs pour mesurer distance parcourue.
4
Évitement d'obstacles : algorithme basique, scan d'obstacles, prise de décision (avancer, tourner, reculer).
5
Suivi de ligne : capteurs IR, calibrage, algorithme PID simplifié pour rester sur la piste.
6
Communication : Bluetooth/WiFi pour contrôler le robot depuis un smartphone ou ordinateur.
🎯
Mini-Projet Construire un robot "robot-tonneuse" : se déplace et évite les obstacles en utilisant des capteurs ultrasoniques.
04

Robotique Articulée : Bras Robotiques

Avancé
⏱ 6 étapes • 4h30
Contrôlez des bras robotiques multi-articules. Apprenez la cinématique directe/inverse et la programmation de trajectoires.
1
Degrés de liberté (DOF) : articulations prismatiques et rotoïdes. Espaces de travail et limites articulaires.
2
Cinématique directe : calculer la position de l'effecteur à partir des angles articulaires. Matrices de transformation.
3
Cinématique inverse : déterminer les angles nécessaires pour atteindre une position. Méthodes analytiques et numériques.
4
Servo-moteurs : contrôle précis, synchronisation, retours de position. Communication avec Arduino/Raspberry Pi.
5
Planification de trajectoires : mouvements fluides, évitement de collisions, temps d'exécution optimal.
6
Projets avancés : robot manipulateur, pick-and-place, vision par caméra pour reconnaître objets.
🎯
Mini-Projet Programmer un bras à 3 articulations (avec servo) pour saisir un objet à différentes positions et le déplacer.
05

Informatique Embarquée et IoT

Avancé
⏱ 5 étapes • 4h
Intégrez vos robots à Internet des Objets (IoT). Communiquez avec d'autres appareils et créez des écosystèmes connectés.
1
Raspberry Pi : installation Raspbian, SSH, interfaçage GPIO. Puissance de calcul vs Arduino.
2
Programmation Python pour robotique : librairies GPIO, timing, multithreading pour tâches parallèles.
3
Connectivité WiFi/Ethernet : API REST, MQTT pour communication légère. Cloud computing et stockage distant.
4
Machine Learning sur appareils embarqués : TensorFlow Lite, classification d'images, reconnaissance vocale.
5
Sécurité IoT : chiffrement, authentification, mises à jour. Protéger vos robots contre les accès non autorisés.
🎯
Mini-Projet Créer un robot connecté qui envoie des données (température, distance) à un serveur cloud et reçoit des ordres.
06

Projet Final - Robot Complet

Expert
⏱ 7 étapes • 20h+
Concevez et construisez un robot complet du début à la fin : mécanique, électronique, programmation et test final.
1
Conception : cahier des charges, croquis, modélisation 3D. Définir la fonction du robot (navigation, manipulation, etc.).
2
Mécanique : assemblage du châssis, motorisation, articulations. Tests des degrés de liberté.
3
Électronique : intégration Arduino/Raspberry Pi, câblage des moteurs, capteurs et alimentations.
4
Programmation : code de démarrage, contrôle moteurs, lecture capteurs. Boucle de contrôle optimisée.
5
Algorithmes : navigation autonome, évitement d'obstacles, suivi d'objets ou de lignes.
6
Test & Intégration : tester tous les systèmes, déboguer, optimiser performance et autonomie.
7
Documentation & Présentation : rapport technique complet, démonstration vidéo, améliorations futures.
🏆
Projet Final Créer un robot autonome complet (roulant ou articulé) avec navigation, capteurs intelligents et capacités d'apprentissage. Documentez le projet avec photos, vidéos et rapport technique.

Animation 6 Modules Motion Design

01

Fondamentaux de l'Animation

Débutant
⏱ 6 étapes • 2h30
Découvrez les 12 principes de l'animation des studios Disney : timing, easing, anticipation. Les bases indispensables avant de toucher à un logiciel.
1
Les 12 principes de l'animation : timing, ease in/out, anticipation, mise en scène (staging), arcs de mouvement.
2
Keyframes et inbetweening : poses clés, images intermédiaires, lecture fluide du mouvement.
3
Courbes d'easing : linéaire, ease-in, ease-out, ease-in-out. Impact sur la perception du mouvement.
4
Squash & stretch, follow through et overlapping action pour donner du poids et de la vie aux objets.
5
Timing musical : BPM, temps forts, synchronisation d'une animation sur une piste audio.
6
Panorama des outils : After Effects, Blender, Principle, CSS/JS pour le motion design web.
🎯
Mini-Projet Animer une simple balle rebondissante en appliquant squash & stretch, anticipation et easing correct.
02

Keyframes & Interpolation Avancée

Intermédiaire
⏱ 6 étapes • 3h
Maîtrisez l'éditeur de courbes et les techniques d'interpolation pour des animations professionnelles et fluides.
1
Graph editor / courbe d'animation : manipuler les tangentes, lisser une trajectoire.
2
Interpolation linéaire vs bézier vs constante (pas à pas). Cas d'usage de chacune.
3
Loops et cycles d'animation : boucles parfaites, animations répétitives (marche, respiration).
4
Parenting et hiérarchies d'objets : animer un groupe d'éléments liés entre eux.
5
Masques et matte animés pour révéler ou cacher des éléments progressivement.
6
Optimisation : réduire le nombre de keyframes sans perdre en fluidité, performance à l'export.
🎯
Mini-Projet Créer une animation logo en boucle parfaite de 3 secondes avec courbes d'easing personnalisées.

Animation de Personnages

Intermédiaire
⏱ 6 étapes • 4h
Donnez vie à des personnages : rig basique, cycles de marche et expressions faciales.
1
Rigging basique : squelette, articulations, points de contrôle pour un personnage 2D/3D simple.
2
Cycle de marche : les 8 poses clés, répartition du poids, décalage des bras/jambes.
3
Expressions faciales et lip-sync : phonèmes principaux, synchronisation avec la voix.
4
Pose to pose vs straight ahead : deux méthodes de travail, avantages selon le contexte.
5
Secondary action : mouvements secondaires (cheveux, vêtements) qui renforcent le réalisme.
6
Exaggeration et appeal : accentuer les poses pour un impact visuel et un style attachant.

Mini-Projet Animer un cycle de marche complet (8 poses) pour un personnage simple type bonhomme allumette.

Prise en main d'un logiciel 3D (Blender) : navigation, objets, transformations de base.

Motion design 2D/3D pour le web et les réseaux : titrages animés, infographies dynamiques.

Rendu et export : formats vidéo, résolution, compression selon la plateforme cible.

Mini-Projet Réaliser une courte animation 3D (10-15s) : objet qui tourne, caméra en mouvement, éclairage soigné.

Effets Spéciaux & Sound Design

Systèmes de particules : fumée, étincelles, pluie. Paramètres de base (émission, gravité, durée de vie).

Morphing et distortion : transformer un objet en un autre de façon fluide.

Implémentez le pattern Observer avec une classe. (En lien avec le Module 04 - POO Avancée & Design Patterns)
📖 Petite leçon avant de commencer ▾
Rappel express : le pattern Observer

  • Utile chaque fois que plusieurs parties d'une application doivent réagir à un même événement.
